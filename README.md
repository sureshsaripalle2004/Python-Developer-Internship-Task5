# Python Developer Internship - Task 5

##  Task Name
Data Analysis on CSV Files using Pandas

##  Objective
The objective of this task is to analyze a sales dataset using the Pandas library in Python. The dataset is loaded from a CSV file, explored to understand its structure, analyzed using grouping operations, and visualized with bar charts.

---

##  Tools & Technologies
- Python 3
- Google Colab
- Pandas
- Matplotlib
- GitHub

---

##  Dataset
**File Used:** `Sales Report.csv`

The dataset contains product inventory details such as:
- SKU Code
- Design Number
- Stock
- Category
- Size
- Color

---

##  Analysis Performed
The following operations were performed on the dataset:

- Loaded the CSV file using Pandas
- Displayed the first and last records
- Checked dataset information
- Generated statistical summary
- Checked missing values
- Grouped stock by Color
- Grouped stock by Size
- Grouped stock by Category
- Filtered products based on stock
- Sorted products by stock
- Identified highest and lowest stock items
- Created bar charts for visualization

---

##  Charts Generated
- Stock by Color
- Stock by Size
- Stock by Category
